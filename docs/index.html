Курс-тест для ассистентов

9 практических задач по настройке ИИ-ассистентов. Время: 6-9 часов.

Как проходить

  1. Открой задачу, прочитай сценарий и шаги. Внутри — материалы для тренировки.
  2. Заполни форму ответа внизу страницы задачи (две секции — ФИНАЛ и ЛОГ) и нажми «Сохранить ответ». Файл с ответом скачается тебе на компьютер.
  3. Когда сделаешь все 9 — собери скачанные файлы в одну папку, сожми в ZIP и отправь.
