## 🧠 Главные архитектурные решения (зафиксированы в концепции)

1. **🦴 Скелет + 💪 Мышцы** — детерминированная логика работает первой, ИИ накладывается опционально с graceful degradation.

2. **Proxy-коммуникации** (главная идея Коли, аналог Midjourney в Discord) — все коммуникации через платформу:
   - Кандидаты/Ассистенты → TG-бот
   - Дмитрий/Коммуникатор → Дашборд (или Manager Hub bot)
   - Платформа посередине логирует, шаблонизирует, доставляет
   - Никаких «договорённостей в личке»

3. **Кнопки вместо реакций в чате** — задача приходит адресно в личку с inline-кнопкой «Принять / Отказ». Round-robin в MVP, умный выбор в Доработке.

4. **Multi-brain с JSON-контрактами** — каждый ИИ-агент решает узкую задачу, отчитывается другому через Zod-схему. Защищает от галлюцинаций.

5. **MVP без ИИ** — Дмитрий сам нажимает кнопки оценки. ИИ-оценщик в Доработке I.

6. **Ревью с умышленными ошибками** — обязательная часть в Развитии II (не в MVP — слишком тяжёлая для старта).

## ⚠️ Технические нюансы которые нужно помнить

### Vercel
- Проект в Vercel называется **`site`** (не `assistant-hub` — он был сломан с UNKNOWN деплоями)
- Алиас `assistant-hub-7k9p2x.vercel.app` указывает на `site` проект
- **Автодеплой при push сломан** — после правок `site/index.html` нужно вручную: `cd site && vercel --prod --yes`
- Vercel Auth включён — посторонние не зайдут даже зная URL
- Если нужно показать Дмитрию ссылкой — отключить protection в Vercel Dashboard

### Git
- gh CLI авторизован как `kokolsk1y`
- Репо приватный
- `.gitignore` исключает: dmitry-docs/, .env, *.zip, .vercel
- Имя в коммитах: «Коля» (исправлено везде, было «Илья»)

### OpenClaw
- На нативном Windows нестабилен — обязателен WSL2
- В MVP его НЕТ — используем прямые вызовы OpenRouter из Python
- OpenClaw появляется в Развитии II когда понадобятся продвинутые multi-agent сценарии

### Python
- Python 3.14.3 уже установлен у Коли (Windows Store)
- Для разработки нужен Python в WSL2 (3.12+)
- Библиотеки: `aiogram 3.x`, `asyncpg`, `openai` (для OpenRouter), `pydantic`, `apscheduler`, `python-docx`, `openpyxl`
