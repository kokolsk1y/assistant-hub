## Стек

- **Python aiogram 3** — Telegram-бот (MVP)
- **Neon Postgres** — данные, FSM, история, метрики, **бизнес-правила** (грейды, типы ошибок, коэффициенты доработки)
- **OpenRouter** — Claude Sonnet 4.6 / Haiku 4.5 / Opus 4.7 (с Доработки I)
- **OpenClaw** — мульти-агентный фреймворк (с Развития II)
- **APScheduler** — напоминания и cron-задачи

## Архитектурные принципы

- **Скелет сначала, ИИ потом.** Детерминированная логика (БД, FSM, маршрутизация) работает без ИИ. ИИ — слой улучшения поверх работающего скелета.
- **Все правила в Neon с первого дня.** Грейды, типы ошибок, коэффициенты, окно тендера, чек-листы peer-review — всё в БД. Когда подключатся ИИ-агенты (D1, D4, R1, R3), они читают из того же источника что и код.
- **Multi-brain.** Каждый ИИ-агент решает узкую задачу, отдаёт результат в JSON-схеме. Без галлюцинаций и кросс-агентных ошибок.
- **Декомпозиция:** максимум 8 часов на фазу. Каждая фаза самостоятельная.

## Команда

- **Коля** — разработчик
- **Евгений** — разработчик + коммуникатор (созвоны со «спорными» кандидатами, мотивация, арбитраж)
- **Дмитрий, Александр** — менеджеры/заказчики, дают задачи и принимают отчётность. В операционке не сидят.

## Процесс работы

1. Коля + Евгений вместе разбивают фазу на задачи.
2. Делают, взаимно ревьюят друг друга по этапам.
3. По завершении фазы — отчёт батчем в общий чат с Дмитрием и Александром.
4. Менеджеры дают добро или возвращают на доработку.
