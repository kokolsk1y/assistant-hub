# Регламент оценки агентов

Каждый из 9 ИИ-агентов, который собирает контент одной задачи, оценивается по **5 критериям × 2 балла = 10 баллов**.
Если **< 8/10** — отправляем агента на переделку с конкретными замечаниями. Если **< 6/10** — переделываем сами.

| # | Критерий | 0 | 1 | 2 |
|---|---|---|---|---|
| 1 | **Полнота артефактов** (есть всё что просили: yaml + hidden tests + training + сломанный промпт если нужно) | Нет половины | Есть, но дыры | Все артефакты на месте |
| 2 | **Корректность ассертов** (assertions реалистично проверяют то, что заявлено в задаче — длина, стоп-слова, JSON-схема, llm-rubric с осмысленным промптом) | Ассерты случайные / не проверяют суть | Часть проверяет, часть мимо | Каждый ассерт прибит к конкретной грани навыка из задачи |
| 3 | **Качество тест-сета** (≥15 кейсов, разнообразие, не дублируют тренировочные, ловят разные грани) | <10 кейсов или копия тренировки | 10-14 или однообразие | ≥15, разнообразие, ловушки на пограничные случаи |
| 4 | **Запускаемость** (yaml валиден, пути к файлам корректны, `promptfoo eval` стартует без ошибок парсинга) | Не запускается | Запускается с правками | Запускается из коробки |
| 5 | **Соответствие final.html** (нет отсебятины, формат промпта-задачи близок к описанию, метрика совпадает с указанной в final.html) | Сильное отклонение | Незначительные расхождения | Точно по описанию задачи |

## Процесс ревью

1. Агент пишет файлы.
2. Главный (я, Claude) прогоняет чек-лист на каждый артефакт.
3. Выставляю оценку 0-2 по каждому критерию, считаю сумму.
4. Если ≥8 — принимаю. Если <8 — формирую список конкретных замечаний и отправляю агента на доработку (повторный запуск с уточнённым промптом).
5. Максимум 2 цикла переделки. Если после второй ещё <8 — переделываю руками.

## Финальная проверка всей системы

После сборки всех 9 задач + оркестратора:

- **End-to-end тест:** взять fixture-сдачу хотя бы для 2 задач, запустить `npm run eval -- --task 01 --submission fixtures/task01/`, убедиться что:
  - оркестратор парсит финальную конфигурацию из сдачи;
  - `promptfoo eval` запускается на hidden-тест-сете;
  - LLM-судья оценивает лог по 4 пунктам;
  - выдаётся итоговый балл 0-10 в читаемом виде.
- **Калибровка:** прогнать сильную и слабую сдачу, убедиться что разброс баллов адекватный (сильная >7, слабая <5).
