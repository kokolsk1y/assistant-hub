## ФАЗА C — Механизм сдачи (in-browser форма)

**Цель:** кандидат заполняет ответ прямо на странице, нажимает кнопку → скачивает `task-01-иван-петров.md`.

**Решение:** чистый JavaScript, никакого backend. Каждая task HTML страница получает:
- Поле «Твоё имя» (заполняется один раз, сохраняется в `localStorage`)
- Текстовые поля ФИНАЛ и ЛОГ прямо на странице (вместо или рядом с кнопкой «Скачать шаблон»)
- Кнопка «Сохранить ответ» → генерирует `.md` файл с правильным именем и скачивает

| ID | Задача | Кто | Статус | Проверка |
|----|--------|-----|--------|----------|
| C1 | Написать JS-функцию `generateMd(taskNum, name, final, log)` → возвращает строку md-файла | Агент | ✅ | form.js |
| C2 | Написать JS-функцию `transliterate(ruName)` → `ivan-petrov` из `Иван Петров` (для имени файла) | Агент | ✅ | form.js |
| C3 | Написать JS-функцию `downloadFile(filename, content)` → скачивает файл | Агент | ✅ | form.js |
| C4 | Добавить в каждую из 9 task HTML: поле имени + textarea ФИНАЛ + textarea ЛОГ + кнопку «Сохранить ответ» | Агент | ✅ | 9 файлов обновлены |
| C5 | `localStorage` — имя кандидата (на русском) сохраняется и восстанавливается при переходе между задачами | Агент | ✅ | form.js, autosave на input |
| C6 | На index.html: поле имени + прогресс-трекер (галочки/жёлтые кружки по задачам) | Агент | ✅ | index.html обновлён |
| C7 | **Коля проверяет:** ввести имя кириллицей, заполнить форму, скачать — файл называется правильно? | **Коля** | ⬜ | Ввести `Иван Петров` → файл `task-01-ivan-petrov.md`, внутри имя на русском |

> ℹ️ **Для ZIP в браузере** нужна библиотека JSZip (CDN, без установки). Добавляется одним `<script>` тегом.
> Альтернатива если JSZip сложно: просто 9 кнопок «Скачать задачу N» — без общего ZIP. Проще, работает.
