- hidden/README.md, hidden/debug-log-rubric.md
- promptfooconfig.yaml

**4 дефекта в сломанном промпте подтверждены:**
1. Нет null — заменено на «выводи из контекста / домена корпоративной почты»
2. Срыв с JSON — фраза «обязательно поясни в ответе как ты принял решение»

4. Markdown-обёртка — нет оговорки «без ```»

**Ассерты:** `is-json` + `javascript` (JSON.parse + сверка значений) + `not-contains` галлюцинаций.

**К проверке моей:** прочитать tests.yaml на разнообразие и пограничные кейсы.
